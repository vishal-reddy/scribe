# Scribe Boundaries and Interfaces

## HTTP Routes

| Route | Method | Auth | Description |
|---|---|---|---|
| `/api/documents` | GET | Kinde / Session | List user's documents with pagination |
| `/api/documents` | POST | Kinde / Session | Create new document (quota-gated) |
| `/api/documents/:id` | GET | Kinde / Session | Get document content and metadata |
| `/api/documents/:id` | PUT | Kinde / Session | Update document content (quota-gated) |
| `/api/documents/:id/sync` | GET (WS) | Token | Connect to Yjs real-time collaborative editing |
| `/api/quota` | GET | Internal / Token | Fetch user's storage usage breakdown |
| `/d/:obfuscatedId` | GET | Public | View shared document with obfuscated URL |

## MCP Tools

- `create_document`: Create a new document with title, markdown body, and tags.
- `get_document`: Retrieve document text and structure by ID.
- `update_document`: Edit or append text to an existing document.
- `list_documents`: Search and list documents.
- `check_storage_quota`: Inspect collective storage allocation across all office apps.
