# Scribe Database Overview

Scribe persists relational state in Cloudflare D1 (`scribe-db`, ID: `4f10070e-b7be-4922-916d-a41765388d46`).

## Schema Tables

- `documents`: Primary table storing document ID, user ID, organization ID, title, content (Markdown/JSON), byte length, timestamps.
- `document_revisions`: Snapshot history for version rollbacks and diffing.
- `document_shares`: Public sharing links, access permissions, and obfuscated tokens.
- `organizations`: Shared workspaces, billing tiers, member roles (`owner`, `editor`, `viewer`).
- `user_quotas`: Local caching table for fast quota checks and byte accounting.
